Counter-Strike 2 Workshop addon files for our [MapVote](https://github.com/kandru/cs2-mapvote). The plugin, config, and source live in that repository. The published Panorama HUD is on the Steam Workshop.

## Where to go

- **Plugin:** [github.com/kandru/cs2-mapvote](https://github.com/kandru/cs2-mapvote)
- **Workshop addon:** [MapVote (3827322946)](https://steamcommunity.com/sharedfiles/filedetails/?id=3827322946)

Install the plugin from the GitHub releases, then load workshop item `3827322946` with [MultiAddonManager](https://github.com/Source2ZE/MultiAddonManager/releases). Setup steps are in the plugin README.
